# Translation Artifacts

`Xianni_Translation.patch` is a historical decompiler-generated translation diff. It compares older original and translated decompiled source snapshots and was preserved for context.

The patch is noisy. It includes decompiler token, RID, RVA, and offset churn, so it should not be treated as a clean source patch. It can still be useful as secondary translation archaeology when investigating where a localized string or behavior came from.

This directory is not runtime content. Files here are not required to build, deploy, or run the mod.

The primary translation-memory authority remains the external original-vs-translated source trees under:

```text
D:\Workflow\Worldbox Xian Ni work box\Xianni differences
```

Generated comparison reports, smoke logs, screenshots, and session closeouts belong under ignored `reports/` workflow artifacts rather than the repository root.
